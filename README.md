# SE-Buddy

Learn software engineering one puzzle at a time: a learning map, Python coding challenges that run in your browser, quizzes, hints, XP, streaks and achievements. Pure static HTML/CSS/JS.

## Deploy on GitHub Pages
1. Push this repo to GitHub (branch `main`).
2. In the repo go to **Settings > Pages** and set **Source** to **GitHub Actions**.
3. The `Deploy to GitHub Pages` workflow publishes the site on every push to `main`.

## Run locally
    python -m http.server 8000

Open http://localhost:8000. See `arc.md` for the architecture and the reasoning behind it.
